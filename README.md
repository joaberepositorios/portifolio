# Portfólio 3D — Joabe Alves

Site de uma página: um percurso 3D (three.js) por um corredor e uma sala de comando, com as seções do portfólio sobre o cenário. Sem build: HTML, CSS e JavaScript (módulos ES, bibliotecas via CDN).

- `index.html` — o site inteiro
- `3d/` — cenários (glTF comprimido com meshopt)
- `img/` — imagens e ícones

Cenários 3D: “Sci Fi Spacestation Corridor”, de Siamak Tavakoli, e “Sci-Fi Space Room Interior”, de Paul — Sketchfab, CC BY 4.0.
